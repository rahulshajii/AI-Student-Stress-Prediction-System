# AI Powered Student Stress Prediction System
https://ai-student-stress-prediction-system.onrender.com
## Overview

The AI Powered Student Stress Prediction System is a Machine Learning based web application developed using Python, Flask, and Random Forest.

The system predicts student stress levels based on mental health, academic, environmental, and social factors.

---

## Features

* Predict Student Stress Level
* Machine Learning Model (Random Forest)
* Web Application using Flask
* Responsive Bootstrap Interface
* Confidence Score Display
* Personalized Recommendations
* Professional Dashboard

* Student Stress Dataset
* 1100 Records

* 3 Target Classes

* 0 → Low Stress
* 1 → Medium Stress
* 2 → High Stress
